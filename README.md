# MILK10k Lesion Classification Project

## Overview
This project investigates image classification using the MILK10k dataset, with particular attention to label quality, data leakage, lesion-level splitting, image preprocessing, and reproducible evaluation.

## Project Structure
- `data/`: Dataset metadata and local data references
- `src/`: Reusable Python code
- `notebooks/`: Exploratory analysis and homework experiments
- `splits/`: Train, validation, and test split files
- `figures/`: Visualizations
- `reports/`: Project reports
- `artifacts/`: Generated analysis outputs

## Reproducibility
The project will document random seeds, data-splitting rules, and preprocessing decisions.

## Dataset
Raw dataset images are not intended to be committed to this repository.
